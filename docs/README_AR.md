# DEVIL — دليل سريع بالعربي

دي نسخة GitHub جاهزة من **DEVIL v3.1**، فيها الواجهة الفعلية، السكربت المساعد لتوليد بيانات GeoIP، اختبارات، ملفات إعدادات مثال، وتوثيق.

**مش منشورة على GitHub تلقائيًا**، ومش متصلة بحسابك أو بسيرفر الـVPS.

## تعمل إيه؟

1. فكّ ضغط المشروع على الكمبيوتر.
2. أنشئ Repository جديد على GitHub واختر **Private** (مهم علشان المشروع تجاري ولسه مفيش قرار ترخيص عام).
3. ارفع محتويات المجلد للمستودع عبر GitHub Desktop أو Git.
4. **ممنوع ترفع** قواعد `intelligence.db` أو `events.db` أو `geo_enrichment.csv` أو ملفات `telegram.env` أو كلمات المرور أو مفاتيح SSH أو ملف `htpasswd`.
5. علشان تشغل نسخة تجريبية، نفّذ `python3 tools/make_demo_data.py --output /tmp/devil-demo-data`، ثم شغّل `dashboard.py` باستخدام متغير `DEVIL_DATA_DIR`.

## الفرق بين GitHub والـVPS

GitHub هيحتفظ بالسورس والتوثيق والاختبارات. الـVPS هيحتفظ بالبيانات الحقيقية والمفاتيح والشهادات وإعدادات السيرفر. سكربت التحديث في `scripts/deploy.sh` بيتعامل مع Dashboard فقط.

## مهم

- GeoIP تقريبية، مش مصدر هجمات حقيقي.
- Live Pulse مراقبة موارد السيرفر نفسه، مش تحليل لكل أجهزة الشبكة.
- السيرفر الحالي بمواصفات محدودة، وما ينفعش نركّب عليه SIEM تقيل لمجرد إن الواجهة سريعة.
- السكربتات الأصلية القديمة (`collector.py`, `correlator.py`, `telegram_alert.py` وسكربتات الراوتر) لسه محتاجة تتسحب وتراجع **بدون أسرار** قبل إدخالها للمستودع.

اقرأ [DEPLOYMENT.md](DEPLOYMENT.md) للتحديث الآمن، و[SECURITY_CHECKLIST.md](SECURITY_CHECKLIST.md) قبل مشاركة المشروع.
